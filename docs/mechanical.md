# Mechanical design

The enclosure is generated by `mechanical/enclosure.py` from the PCB placement file, so connector
openings follow the board. Regenerate with CadQuery after any placement change.

| | |
|---|---|
| Outer size | 166.8 x 111.8 x 30.9 mm |
| Construction | two shells split at the PCB top surface, 2.4 mm walls |
| Material | PC/ABS, UL 94 V-0, for moulding. PETG or ABS for prototypes |
| PCB mounting | four pillars in the base carry the board, four in the lid clamp it |
| Fasteners | 4x M3 x 25 from below, through the PCB, into M3 heat-set inserts in the lid |
| Clearance below the PCB | 6.5 mm: M.2 socket, SSD and a 1.5 mm thermal pad on a raised land |
| Clearance above the PCB | 18.0 mm: USB stack 15.7 mm, PoE module 14.1 mm |

## Openings

| Opening | Location | Size |
|---|---|---|
| RJ45 | rear | 17.6 x 14.3 mm notch |
| Dual USB-A | rear | 15.8 x 16.3 mm notch |
| USB-C | rear | 9.8 x 3.9 mm notch |
| Power, User, RPIBOOT buttons | top, near the rear | 3x 6 mm holes with captive plungers |
| Antenna bulkheads | right side | 2x 6.6 mm for RP-SMA: Zigbee, optional Wi-Fi |
| Microphone | top right | 1.6 mm port through a 6 mm tube sealed to the PCB |
| Speaker | top | 40 mm grille with retaining ring |
| Mute slider | top front | 11 x 4.4 mm slot |
| Status LEDs | top front | 2.4 mm holes |
| Vents | top and base | slot arrays over and under the CM5 and the PoE module |
| Fan | top, over the CM5 | 4 holes on a 32 mm pitch for a 40 mm fan |

## Files

`mechanical/out/` holds each part as STEP, STL and 3MF: `tahanan-base`, `tahanan-lid`,
`tahanan-button-plunger`, `tahanan-mute-slider`. `tahanan-assembly.step` adds a simplified board.
`hardware/build/tahanan-pcb.step` is the board with component models. It is written by `make docs`.

## Checks done and not done

- Done: the script intersects both shells with solids for the board, the tall components, the CM5 with
  a 10 mm heat sink, and a 2280 SSD. Interference is 0 mm³ for both shells.
- Not done: no part has been printed or fitted. Snap, draft and moulding analysis are not done. The
  shells have no draft angles, so they are print-ready but not mould-ready.
- Not done: the LED holes have no light pipes, and the acoustic path of the microphone and speaker is
  unmeasured.
- The component solids use courtyard outlines, not vendor 3D models. Repeat the fit check against
  `tahanan-pcb.step` once the layout is final.
